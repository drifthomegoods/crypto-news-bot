## Տեղադրում (մոտ 20 րոպե)

### Քայլ 1. Telegram ալիք և բոտ

1. Telegram-ում ստեղծիր նոր **ալիք** (New Channel), տուր անուն, դարձրու **Public** և ընտրիր հղում, օրինակ՝ `@crypto_news_hy`։
2. Գրիր [@BotFather](https://t.me/BotFather)-ին → `/newbot` → տուր բոտի անուն և username (պետք է ավարտվի `bot`-ով)։
3. BotFather-ը կտա **token** (`123456789:AA...` տեսքի)։ Պահիր այն գաղտնի, **ոչ մեկին մի ուղարկիր**։
4. Ալիքի կարգավորումներում → **Administrators** → **Add Admin** → գտիր բոտիդ և տուր **Post Messages** իրավունք։

### Քայլ 2. Anthropic API key (AI ամփոփումների համար)

1. Գնա [console.anthropic.com](https://console.anthropic.com) ու գրանցվիր։
2. **Billing** բաժնում լիցքավորիր հաշիվը (5$-ը բավական է մի քանի ամսվա համար)։
3. **API Keys** → **Create Key** → պատճենիր key-ը (`sk-ant-...`)։

> Ծախսը. AI-ն կանչվում է միայն նոր նորություններ լինելու դեպքում։ Սովորաբար ամսական մի քանի դոլար է։ Ավելի էժան տարբերակի համար տես «Կարգավորումներ»-ը։

### Քայլ 3. GitHub հաշիվ և ռեպո

1. Գրանցվիր [github.com/signup](https://github.com/signup)-ում (անվճար)։
2. Վերևի աջ անկյունում **+** → **New repository**։
   - Անուն՝ օրինակ `crypto-news-bot`
   - Ընտրիր **Public** (այդպես GitHub Actions-ը անսահմանափակ անվճար է, իսկ գաղտնի key-երը միևնույն է պաշտպանված են secrets-ում)
   - Սեղմիր **Create repository**
3. Ռեպոյի էջում սեղմիր **uploading an existing file** հղումը և քաշիր այս թղթապանակի **բոլոր ֆայլերն ու թղթապանակները** (`bot`, `state`, `requirements.txt`, `README.md`)։ Սեղմիր **Commit changes**։
4. `.github` թղթապանակը թաքնված է և կարող է չբեռնվել։ Ստուգիր. եթե ռեպոյում `.github/workflows/news.yml` չկա.
   - Սեղմիր **Add file** → **Create new file**
   - Անվան դաշտում գրիր ճիշտ այսպես՝ `.github/workflows/news.yml`
   - Բացիր այս zip-ի `.github/workflows/news.yml` ֆայլը, պատճենիր ամբողջ պարունակությունը և տեղադրիր
   - **Commit changes**

### Քայլ 4. Գաղտնի key-երը (Secrets)

Ռեպոյում՝ **Settings** → **Secrets and variables** → **Actions** → **New repository secret**։ Ավելացրու երեքը.

| Name | Value |
|---|---|
| `TELEGRAM_BOT_TOKEN` | BotFather-ի տված token-ը |
| `TELEGRAM_CHANNEL_ID` | ալիքի հղումը՝ `@`-ով, օրինակ `@crypto_news_hy` |
| `ANTHROPIC_API_KEY` | Anthropic-ի key-ը (`sk-ant-...`) |

### Քայլ 5. Միացում և ստուգում

1. Ռեպոյում բացիր **Actions** ներդիրը։ Եթե հարցնի, սեղմիր **I understand my workflows, go ahead and enable them**։
2. Ձախից ընտրիր **Crypto news to Telegram** → **Run workflow** → նշիր ✅ **Send only a test message** → **Run workflow**։
3. Մոտ մեկ րոպեից ալիքում պետք է հայտնվի «✅ Բոտը միացված է և աշխատում է»։
4. Նորից գործարկիր **առանց** նշումների։ Առաջին գործարկումը միայն «հիշում է» արդեն եղած նորությունները (որպեսզի ալիքը չողողի հին լուրերով)։ Դրանից հետո բոտը ինքնաշխատ կաշխատի ամեն 30 րոպեն մեկ և կհրապարակի միայն նոր, կարևոր նորություններ։

Պատրաստ է 🎉

## Կարգավորումներ

**Settings → Secrets and variables → Actions → Variables** ներդիրում կարող ես ավելացնել.

| Variable | Լռելյայն | Ինչ է անում |
|---|---|---|
| `MIN_IMPORTANCE` | `7` | Կարևորության նվազագույն շեմը (1–10)։ `8` → ավելի քիչ, միայն շատ կարևոր նորություններ։ `6` → ավելի շատ։ |
| `MAX_POSTS_PER_RUN` | `3` | Առավելագույնը քանի պոստ մեկ ստուգման ընթացքում |
| `CLAUDE_MODEL` | `claude-sonnet-5-5` | `claude-haiku-5-5` → մի քանի անգամ ավելի էժան, մի փոքր պարզ տեքստ |

Աղբյուրների ցուցակը կամ գներով հետևվող կոյները փոխելու համար խմբագրիր `bot/main.py`-ի վերևում `FEEDS` և `TRACKED_COINS` ցուցակները։

## Եթե ինչ-որ բան չի աշխատում

- **Actions**-ում բացիր վերջին գործարկումը → **Run bot** քայլը։ Այնտեղ երևում են սխալները։
- `Telegram error 400: chat not found` → `TELEGRAM_CHANNEL_ID`-ը սխալ է կամ բոտը ալիքի ադմին չէ։
- `Telegram error 401` → token-ը սխալ է։
- `Claude step failed` → ստուգիր `ANTHROPIC_API_KEY`-ը և հաշվի բալանսը։
- GitHub-ի ժամանակացույցը երբեմն ուշանում է 5–15 րոպեով. դա նորմալ է։

## Կարևոր

Նորությունները հրապարակվում են AI-ի կողմից **սեփական բառերով վերաշարադրված** տեսքով՝ բնօրինակ աղբյուրի հղումով, առանց հոդվածների պատճենման։ Ալիքի բովանդակությունը անալիզ է, ոչ թե ֆինանսական խորհուրդ։ AI-ն կարող է սխալվել, այնպես որ կարևոր դեպքերում ստուգիր աղբյուրը։
