# Ոճի ուղեցույց. հայերեն կրիպտո նորություններ

Այս ֆայլը բոտի «սքիլն» է. AI-ն այն կարդում է ամեն անգամ, երբ գրում կամ սրբագրում է պոստերը։
Կարող ես ազատ խմբագրել. փոփոխությունները կգործեն հաջորդ գործարկումից։

## Լեզու և տոն
- Ժամանակակից արևելահայերեն, նոր ուղղագրությամբ (ինչպես Հայաստանում)։
- Լրատվական գործակալության տոն. չեզոք, հստակ, առանց հայփի, առանց էմոջիների։
- Կարճ նախադասություններ (մինչև 20–25 բառ)։ Մեկ նախադասություն՝ մեկ միտք։
- Նորություններում ժամանակը՝ վաղակատար. «հայտարարել է», «հաստատել է», «աճել է»։
- Ներգործական սեռ, ոչ կրավորական, երբ հնարավոր է. «Binance-ը սառեցրել է», ոչ «սառեցվել է Binance-ի կողմից»։

## Կետադրություն
- Վերջակետ՝ միայն հայերեն «։» (ոչ «:» կամ «.»)։
- Չակերտներ՝ «» (ոչ "")։
- Բութ «՝» բացատրող կամ հավելող մասից առաջ. «առաջատարը IBIT-ն է՝ 381 մլն դոլարով»։
- Ստորակետ «որ»-ից առաջ. «հայտարարել է, որ...»։
- Վերնագրի վերջում կետ չի դրվում։

## Թվեր և արժույթ
- Տասնորդականները՝ կետով (6.3), ինչպես ընդունված է կրիպտո ոլորտում։
- Կրճատումներ՝ հազ., մլն, մլրդ, տրլն. «6.3 մլրդ դոլար» կամ «$6.3 մլրդ»։
- Տոկոս՝ «4.7%», առանց բացատի։
- Թվերը վերցրու միայն փաստերից. երբեք մի կլորացրու այնպես, որ իմաստը փոխվի, և մի ավելացրու նոր թիվ։

|---|---|
| exchange | բորսա, կրիպտոբորսա (ոչ «բիրժա») |
| hack, exploit | հաքերային հարձակում, կոտրել |
| withdrawals | միջոցների դուրսբերում |
| deposits | միջոցների մուտքագրում |
| liquidations | լիկվիդացիաներ |
| long / short | long / short |
| whales | խոշոր ներդրողներ (whale-եր) |
| inflows / outflows | ներհոսքեր / արտահոսքեր |
| spot ETF | սփոթ ETF |
| stablecoin | սթեյբլքոին |
| altcoin | ալթքոին |
| token | թոքեն |
| wallet / hot wallet | դրամապանակ / «տաք» դրամապանակ |
| market cap | շուկայական կապիտալիզացիա |
| open interest | open interest (OI) |

Ընկերությունների, կոյների և թիքերների անունները թողնել լատինատառ՝ հոլովական վերջավորությունը գծիկով. Binance-ը, BTC-ի, BlackRock-ի, ETF-ները։

## Խուսափիր (ռուսաբանություններ և կաղապարներ)
- «հանդիսանում է» → «է»
- «բիրժա» → «բորսա»
- «կատարել որոշում» → «որոշել»
- «իրականացնել» (չարաշահված) → կոնկրետ բայ. «գնել», «վաճառել», «սկսել»
- «տվյալ» (չարաշահված) → «այս»
- «հանդեպ» (երբ նշանակում է «դեպի») → «նկատմամբ» կամ վերաձևակերպել
- «ի հայտ եկավ» → «հայտնի դարձավ», «պարզվեց»
- բառացի թարգմանված անգլերեն կառույցներ. նախադասությունը վերակառուցիր հայերենի բնական կարգով

## Կառուցվածք
- **Վերնագիր** (մինչև ~80 նիշ). սկսվում է գլխավոր դերակատարով կամ փաստով, պարունակում է հիմնական թիվը, եթե կա։
- **Տեքստ** (2–4 նախադասություն). ինչ է տեղի ունեցել → հիմնական թվերը → ինչու է կարևոր։
- **Ազդեցություն** (1 նախադասություն). ինչ կարող է նշանակել շուկայի համար և որ կոյների։ Վերլուծություն է, ոչ թե խորհուրդ. մի գրիր «գնեք», «վաճառեք»։

## Օրինակներ (թվերը պայմանական են, մի պատճենիր փաստերը)

**Փաստեր.** Binance said a security breach led to about $6.3 billion in losses. About $3 billion has been frozen on-chain. Withdrawals are paused; Binance pledged to cover all user losses.

- Վերնագիր. Binance-ը ենթարկվել է հաքերային հարձակման. դուրս է բերվել մոտ 6.3 մլրդ դոլար
- Տեքստ. Binance կրիպտոբորսան հաստատել է հաքերային հարձակումը, որի հետևանքով դուրս է բերվել մոտ 6.3 մլրդ դոլարի ակտիվ։ Մոտ 3 մլրդ դոլարն արդեն սառեցվել է բլոկչեյնում։ Բորսան դադարեցրել է միջոցների դուրսբերումը և խոստացել է ամբողջությամբ փոխհատուցել օգտատերերի վնասները։
- Ազդեցություն. Կարճաժամկետ ճնշում BNB-ի և ամբողջ շուկայի վրա. ռիսկը կնվազի, եթե դուրսբերումները ժամանակին վերսկսվեն։

**Փաստեր.** US spot bitcoin ETFs recorded net inflows of $1.1 billion on Tuesday, the largest daily total since October 2025, led by BlackRock's IBIT with $381 million.

- Վերնագիր. Սփոթ բիթքոին ETF-ները գրանցել են 1.1 մլրդ դոլարի ներհոսք
- Տեքստ. ԱՄՆ-ի սփոթ բիթքոին ETF-ները երեքշաբթի օրը գրանցել են 1.1 մլրդ դոլարի զուտ ներհոսք։ Սա 2025 թվականի հոկտեմբերից ի վեր ամենամեծ օրական ցուցանիշն է։ Ներհոսքերի առաջատարը BlackRock-ի IBIT-ն է՝ 381 մլն դոլարով։
- Ազդեցություն. Ինստիտուցիոնալ պահանջարկի աճը սովորաբար աջակցում է BTC-ի գնին. կարևոր է՝ արդյոք ներհոսքերը կշարունակվեն։
